# 色彩渐变流动背景 · Gradient Flow

> 本项目作者完全不懂开发，所有代码、功能都是 AI 写的，包括这份说明文档。如果有低级错误，请见谅。

![暖橙配色：两侧是参数面板，中间是缓慢流动的渐变背景](assets/amber.jpg)

一个网页工具：做出**会缓慢流动的彩色渐变背景**。纯 WebGL 实时渲染，零依赖、离线可用、不用安装任何东西。

配色来自 10 套预设 + 色带上 12 个可手改的取色点；可以调玻璃质感、颗粒、扭曲，导出静帧 / 序列帧，
或者直接导出一段能嵌进自己网页的背景代码。

## 三种打开方式

| 方式 | 怎么做 | 适合 |
|---|---|---|
| **单文件版** | 下载 [`gradient-flow.html`](gradient-flow.html)，双击打开 | 发给别人 / 离线用。整个工具就一个文件，约 180 KB |
| **在线版** | 打开 <https://afeiisfine.github.io/gradient-flow-background/> | 不下载，直接看效果 |
| **源码版** | `index.html`、`app.js`、`styles.css` 放同一目录，双击 `index.html` | 想改代码 |

单文件版和源码版是同一份程序：它由 `tools/build-standalone.py` 把 CSS 与 JS 内联生成，
改完源码重跑一次脚本即可，不会出现两份逻辑各自漂移。

## 功能

**配色**

- 10 套预设：黑白、雾白、暖橙、深海、粉紫、青碧、暮色、沙金、幻彩、曜石
- 色带上 12 个取色点，点开内联取色器改色（HSV / HEX）
- 明度、对比度、饱和度、色相整体调整

**动态**

- 2–10 个色块，各自沿噪声路径缓慢漂移
- 速度、色块大小、随机性可调；「换一个构图」重抽一套随机种子
- 域扭曲（domain warp）把圆形色块揉成流动的指状边缘

**质感**

- 颗粒、暗角、边缘柔和、扭曲强度、色块间隙
- 玻璃：毛玻璃 / 长虹 / 橘皮 / 布纹 / 方格，带总开关
- 后四种不做模糊，而是用程序化高度场的梯度去位移采样坐标——是真折射，不是叠一张纹理

**输出**

- 单帧 PNG
- PNG 序列：1–30 秒、24 / 30 / 60 fps、720p / 1080p / 1440p / 竖屏，打包成 zip
- 网页背景代码：导出一个自包含 HTML（WebGL + 纯 CSS 降级），参数冻结在文件里

**其他**

- 中 / 英双语
- 渲染画质三档（0.6× / 1.0× / 1.5×），掉帧时可以先降档
- 参数存在 localStorage，刷新不丢；「恢复出厂设置」一键还原

## 原理：三趟渲染

参考视频里那种「色雾」，本质是几个大而柔的色块在缓慢漂移、边缘互相渗染。所以：

```
① 场趟：每个色块取一个色带坐标 u_i，按"相对最近色块"的指数核算权重，
       在色带坐标里混合（不是 RGB 里），写进 RGBA16F 离屏纹理
② 模糊趟：横向 → 纵向可分离高斯（毛玻璃的主体；玻璃强度为 0 时整趟跳过）
③ 合成趟：程序化玻璃高度场 → 梯度 → 位移采样坐标（折射）
       → 暗角 / 表面高光 / sRGB → 两层 TPDF 抖动
```

**为什么场与合成要分开**：毛玻璃需要真正的低通滤波，而单趟片元着色器采样邻居只能拿到邻居的
**屏幕像素**、拿不到邻居的**场坐标**，所以必须先把场写进离屏纹理再做高斯。

## 文件

```
index.html                  页面结构（源码版入口）
app.js                      全部逻辑 + 着色器（约 2700 行）
styles.css                  界面样式
gradient-flow.html          单文件版（构建产物，可直接分享）
tools/build-standalone.py   生成单文件版的脚本
assets/                     README 演示图
```

## 本地构建单文件版

```bash
python3 tools/build-standalone.py
```

会把 `styles.css` 与 `app.js` 内联进 `index.html`，写出 `gradient-flow.html`，
并自检产物里不再残留任何外部文件引用。

## 浏览器要求

需要 **WebGL2**（Chrome / Edge / Firefox / Safari 15+ 均可）。
显卡不支持 `EXT_color_buffer_float` 时自动走锐利路径：跳过模糊趟，画面仍可用。
